1.3 Exact Math: Streaks, Completion Rate & Today's Momentum
A. Flexible Weekly Streak Algorithm (src/lib/calculations/index.ts)
Replace the rigid consecutive-day loop in calculateCurrentStreak(habit, completions, today) with schedule-aware logic:

If frequencyType === 'daily': Keep current consecutive-day logic (treating frozen as pass-through).

If frequencyType === 'specific_days': Walk backwards day-by-day. If a date's dayOfWeek is NOT in scheduledDays, skip over it transparently (if user completed it anyway, count as +1 bonus). If it IS in scheduledDays, require completed or frozen.

If frequencyType === 'weekly_flexible' (e.g., Gym 5×/week):

Group completions into calendar weeks (Mon–Sun, configurable via weekStartsOn).

Weekly Streak (weeklyStreak): Count consecutive completed past weeks where completedCount >= targetDaysPerWeek (plus the current in-progress week if it is still mathematically achievable: completedThisWeek + remainingDaysInWeek >= targetDaysPerWeek, OR already met).

Continuous Day Streak (currentStreak): Walk backwards day-by-day; a day passes if:

status === 'completed' (+1 to day streak), OR

status === 'frozen' (pass-through, +0), OR

status === 'rest' (or empty day inside a week whose total completed >= targetDaysPerWeek, or inside the current week where nonCompletedDaysSoFar <= 7 - targetDaysPerWeek) (pass-through, +0).

Result: If you do Gym Mon, Tue, Wed, mark Thu as Rest, and do Fri, Sat — your streak stays unbroken and displays 5d 🔥 · 5/5 wk!
